## The product

FirstX is a SaaS product from 10X Ventures that helps founders find their first customers through organic outreach on Twitter. It suggests who to contact, helps correct and improve messages, and steers users away from patterns that get accounts flagged as spam or as bots. The Twitter API is the main channel.

## My part

I worked remotely with a US-based team of full-stack engineers. The stack was Blitz.js, a full-stack React and Node.js framework built on Next.js, with PostgreSQL and Prisma for data and Tailwind CSS with SCSS for styling.

My main contributions were in how the app used the Twitter API and how it handled heavy work:

- **Twitter API usage.** I optimized how the outreach features called the Twitter API.
- **Background processing with queues.** Heavy tasks moved out of the request cycle and into queued background jobs, so users were no longer waiting on slow work to finish.

Together these significantly improved the app's performance and the experience of using it.
